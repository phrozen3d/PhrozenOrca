## 6. 驗收

- [ ] 6.1 auto generate → 沿 X 軸鏡像 → 進支撐模式：支撐點貼合鏡像後表面，無整排位移或間距拉開
- [ ] 6.2 auto generate → 繞 X / Y 軸旋轉 → 進支撐模式：同上
- [ ] 6.3 **gizmo 開啟中執行變換**：不關閉 gizmo 直接鏡像／旋轉，preview 立即反映新座標
- [ ] 6.4 **gizmo 關閉中執行變換**：關閉後鏡像／旋轉再重開，preview 正確
- [ ] 6.5 **Z 旋轉不失效**：繞 Z 軸旋轉 90 度，支撐點數量與內容不變、不觸發重新生成、隨物件轉動且持續貼合
- [ ] 6.6 **XY 平移不失效**：移動物件位置，支撐點數量與內容不變、不觸發重新生成
- [ ] 6.7 **手動點不被刪除**：`UserModified` 狀態下鏡像與非 Z 旋轉後，手動點仍存在且數量不變
- [ ] 6.8 **per-point 參數不變**：帶不同頭部直徑的手動點，鏡像後各自參數與變換前完全相同
- [ ] 6.9 連續執行 Z 旋轉 → 非 Z 旋轉 → 鏡像，每一步後 preview 皆正確，無需重開 gizmo 才修正的中間狀態
- [ ] 6.10 法線快取隨點集失效：變換後 cone 朝向依新表面重算，無舊法線殘留
- [ ] 6.11 幾何快取未被誤清：變換後穩態每幀 `GLModel::init_from()` 呼叫次數仍為 0
- [ ] 6.12 picking 與顯示一致：變換後 hover / click 的命中位置與可見錐體相符
- [ ] 6.13 切片輸出與變換後的 preview 一致
